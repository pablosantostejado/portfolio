# Portafolio Personal - Pablo Santos Tejado

Bienvenido al repositorio de mi portafolio web académico y personal. 

Soy estudiante de 5º curso del Doble Grado en Física y Matemáticas en la Universidad de Salamanca. Utilizo este espacio para documentar y presentar mis proyectos personales, desarrollados como método para aplicar herramientas computacionales a problemas teóricos y prácticos.

## Áreas de interés
* Análisis y visualización de datos
* Modelado matemático
* Simulación física y procesos estocásticos
* Métodos numéricos

## Estructura del repositorio
El portafolio está construido con HTML, CSS y JavaScript puro, gestionando el contenido de forma dinámica.
* `index.html`: Estructura principal e interfaz de la página.
* `data.json`: Base de datos local que contiene la información de mi perfil, experiencia y proyectos.
* `imagenes/`: Directorio con las capturas de los proyectos y recursos gráficos.
* `CV_1.pdf`: Mi currículum académico y profesional.
